O que estudar

Uma trilha sugerida para quem está começando em programação. Clique em uma pergunta para ver a resposta.

1. Por onde começar a estudar programação?

Pela lógica de programação, que é a base de qualquer linguagem. Estude:

  • Variáveis e tipos de dados
  • Operadores e expressões
  • Condicionais (if / else)
  • Laços de repetição (for / while)
2. Como trabalhar em equipe e guardar o código?

Com Git e GitHub, que registram o histórico do projeto e permitem que várias pessoas trabalhem juntas. Estude:

  • Repositório, commit e branch
  • Push e pull
  • Issues e Pull Requests
3. Como criar a estrutura e o visual de uma página?

Com HTML e CSS. O HTML monta o conteúdo e o CSS cuida da aparência. Estude:

  • Tags, listas, links e formulários
  • Seletores, cores e fontes
  • Layout e responsividade
4. Como deixar a página interativa?

Com JavaScript, a linguagem que roda no navegador. Estude:

  • Variáveis, funções e eventos
  • Manipulação do DOM
  • Arrays e objetos
5. Como guardar e consultar informações?

Com banco de dados. Estude:

  • Modelagem de dados
  • SQL (SELECT, INSERT, UPDATE, DELETE)
  • Relacionamentos entre tabelas

Ferramentas

Principais ferramentas utilizadas no desenvolvimento do projeto:

  • VS Code: Editor de código-fonte utilizado para estruturar o projeto.
  • Git e GitHub: Ferramentas de versionamento de código e controle de tarefas em equipe.
  • HTML5 e CSS3: Tecnologias base para a construção e estilização das páginas web.

Objetivo

Objetivo Geral: Desenvolver um guia prático e acessível para orientar iniciantes no universo da programação.

Objetivos Específicos:

  • Apresentar uma trilha de estudos estruturada para novos programadores.
  • Divulgar as principais linguagens de programação do mercado.
  • Facilitar o trabalho colaborativo utilizando metodologias ágeis e controle de versão.
